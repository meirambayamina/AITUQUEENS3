RUN LOCALLY
Extract the whole ZIP, open the AITU_QUEENS_ASSIGNMENT_4 folder, then open index.html in a modern browser. No installation or build step is needed. Bootstrap and all images are included locally. The project also works through a static HTTP server.

FIVE JAVASCRIPT FEATURES
1. Contact page: required name, email, message, demo password, matching confirmation and agreement. The project uses a minimum of 8 password characters. Phone is required only if Phone is selected. Errors appear beside each invalid field; valid submissions show a local confirmation and clear both password fields.
2. Home page: four FAQ questions. Click or use Enter/Space to open and close each answer with a smooth transition.
3. Subscribe button on the seven main pages: opens a newsletter demonstration dialog. Close it with the close button, an outside click or Escape. Name and email are validated.
4. Change background button: cycles Cream, Rose, Sage and Lavender. Reloading restores Cream.
5. Date/time: uses the browser's local timezone and updates every second on all eight HTML pages.
